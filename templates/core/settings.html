Backups

Create an encrypted archive of the database and media:

python manage.py backup

Restore the database and media, then verify:

python manage.py decrypt_backup /data/backups/...
tar -xzf datasnapper-backup.tar.gz -C /data
python manage.py migrate
python manage.py verify_audit

Important: keep /data/secret.key and /data/field.key in a password manager. The field key decrypts identity documents and encrypted backups; without it, those files cannot be recovered.

Security

  • Sign in is required for every page.
  • Identity documents are encrypted at rest with the field key.
  • The audit log is hash-chained; run verify_audit to check it.
  • Serve over HTTPS if the portal is reachable from outside your LAN.
  • No telemetry and no external calls except the links you click.
